* git upstream concept
its nothing but a nickname for a repository yrl<br>
for example<br>
git remote add upstream git@github.com:fuqyumeen/typeshit.git<br>


youre telling github<br>
"when i say upstream, use this repository URL"<br>

git merge upstream/master<br>
it means<br>

-upstream -> original repository<br>
-master -> its master branch<br>
-git merge -> integrate its changes into your currently checked-out branch<br>
