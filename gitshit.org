* git upstream concept
its nothing but a nickname for a repository yrl
for example
git remote add upstream git@github.com:fuqyumeen/typeshit.git


youre telling github
"when i say upstream, use this repository URL"

git merge upstream/master
it means

-upstream -> original repository
-master -> its master branch
-git merge -> integrate its changes into your currently checked-out branch
